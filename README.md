# scalar-aws-assessment

AWS Route 53 console clone assessment.

## Structure

- `frontend/` — Next.js + Cloudscape UI
- `backend/` — FastAPI backend (in progress)
- `PRD-Route53-Clone.md` — Product requirements

## Frontend setup

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
